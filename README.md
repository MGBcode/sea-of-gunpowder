# Sea of Gunpowder

RPG tático roguelike por turnos com temática de piratas, desenvolvido em C99
com Raylib 5.5. Clique em uma célula do tabuleiro para selecioná-la, use F1–F7
para alternar entre as telas do protótipo e pressione Esc para sair.

## Compilar e executar

1. Compile: `make`
2. Execute: `.\build\jogo.exe` no Windows ou `./build/jogo` no Linux.
3. Antes de compactar para entrega, limpe os binários: `make clean`

Veja [REQUIREMENTS.md](./REQUIREMENTS.md) para instalar o compilador, o Make e
a Raylib.
